# 个人博客起步工程

GitHub Pages + Jekyll + Minima。本地无需安装 Ruby，推送后由 GitHub 构建。

完整搭建、发文、Obsidian 配合、分发与排错说明见 [中文教程](guides/GitHub-Pages完整搭建教程.md)。

配置暂按已连接 GitHub 账号 `zhiweiyi11` 填写。使用其他账号时修改 `_config.yml` 中的 `url` 和 `github_username`。

首次发布：建立对应的公开用户站点仓库，上传本工程，进入 Settings → Pages，选择 Deploy from a branch → main → /(root)。

本工程未执行远程发布；本地也未安装 Jekyll。实际构建结果以首次 Pages 构建日志为准。
